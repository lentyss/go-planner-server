# Go Planner Server - планировщик задач

Позволяет создавать задачи, назначать их на конкретную дату и время, удалять и изменять. Если задача выполнена, то ее можно отметить, как завершенную.

## Функционал

- Управлнение жизненным циклом задач, а именно их создание/чтение/изменение и удаление

- Реализован поиск задачи

- Аутентификация через JWT

- Выполнены правила повторения задач

- БД SQLite

## Задания со звездочкой (дополнительно)

- Переменная окружения `TODO_PORT` для определения порта

- Переменная окружения `TODO_DBFILE` для определения пути к бд

- Реализованы все правила повторения (w, m как дополнительные)

- Выполнены задания поиска по дате и тексту

- Аутентификация

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Миграции сделаны через встройку sql-скриптов с помощью директивы `//go:embed`.

### Сервер запускается по адресу: http://localhost:7540

## Запуск

1. Установить зависимости:
   go mod download

2. Настройки переменной окружения:
   Получение токена (curl -X POST http://localhost:7540/api/signin \
    -H "Content-Type: application/json" \
    -d '{"password":"ВАШ_ПАРОЛЬ"}')

3. Локальный запуск:
   go run main.go

4. Запуск тестов:
   go test -v ./tests
